# Security

jen runs agents in containers, keeps the model key in its runtime, and keeps agents off the internet. If you find a way around any of that, or any other security problem, please tell us privately.

**Report it through [GitHub's private vulnerability reporting](https://github.com/reveer-ai/jen/security/advisories/new)**, not in a public issue or pull request. Say what you found, how to reproduce it, and which version of jen (`npm ls -g jen-ai`, or the commit of a checkout) you tried.

We'll answer within a few days, and keep you updated until it's fixed. Only the latest release is supported, so fixes land in a new release.

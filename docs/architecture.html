jen Agent Components

What runs inside one agent container on main as of JEN-9: an HTTP server in front of a turn loop, a SQLite conversation store, and a model port with one adapter.

One turn, in order

  1. The client sends POST /messages with a bearer token. The server rejects it with 409 if a turn is already running.
  2. respond loads the whole conversation from the store and hands it to runTurn with the new text.
  3. The loop calls model.next through the port. The adapter maps items to an OpenAI Responses request and maps the output back.
  4. If the model asked for tools, the loop runs them and calls the model again. With no tool calls, the turn ends.
  5. respond appends the turn's items to SQLite in one transaction. A failed turn saves nothing.
  6. The server replies with the assistant text and pushes the new items to every open GET /events stream, read from the store with after(seq).

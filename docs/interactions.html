jen Agent Interactions

Real runs of the behavior check, replayed. Each run starts with the owner's message to a root agent, and every line below is an item one agent saved, in the order they were saved.

  • Blue arrows are messages going down: the owner to the root, or a parent to a sub-agent with message_sub_agent. Green arrows are replies going up: an agent answers its parent by ending its turn, and its final text is the reply.
  • A parent with sub-agents still working calls wait. The loop answers it with the replies that have arrived, and says who still owes one.
  • A node shows what that agent is doing as of the current step: thinking (its model is being called), calling a tool, waiting, or done with its turn.
